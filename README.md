# ⚔️ Equinox VS - Official Web Portal

الموقع الرسمي لسيرفر ولعبة **Equinox VS** (Conquer Online Private Server).

## 🚀 المميزات (Features)
- 🏰 **الصفحة الرئيسية:** استعراض الشريحة الرئيسية والمميزات ونظام الشخصيات والأنظمة داخل اللعبة.
- 🔐 **تسجيل وتأكيد الحسابات:** نظام تسجيل حسابات جديدة ومزامنتها مع الخادم.
- 👤 **لوحة شخصية اللاعب:** استعراض تفاصيل وتسجيل الدخول للحساب والتحقق من الشخصيات ومستواها وطاقتها القتالية.
- 🛡️ **استعراض الشخصيات (Classes):** تفاصيل تفاعلية لكل فئات اللعبة (تروجان، سيّاف، رامي، حاوي ماء، حاوي نار، نينجا، راهب، قرصان، سفاح، فارس، صاعق).
- 📲 **تحميل اللعبة:** روابط سريعة لتحميل تطبيق APK الخاص بالسيرفر.

## 🛠️ التكنولوجيا المستخدمة (Tech Stack)
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Lucide Icons
- **Backend API:** Next.js Serverless Route Handlers + File System/Database Sync

## 💻 التشغيل المحلي (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev
```

سيتم فتح الموقع على `http://localhost:3000`.
